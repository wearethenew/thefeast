# Fusion Centre renders

Architectural renders of The New Fusion Centre (60A Surulere Industrial Ave, Ogba), downloaded from the church's shared Drive folder "The Fusion Centre". Use them as modelling references only, not as in-game textures.

Most files are 2560×1704; render-07 is 1440×959. They are numbered in the folder's name order, which is the WhatsApp timestamp from 8 Oct 2025.
